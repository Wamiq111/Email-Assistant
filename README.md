# MailReply AI

A complete, polished, beginner-friendly Email Reply Assistant web application.

## Features
- **Multiple Tones**: Choose the communication style that fits your situation (Professional, Friendly, Casual, Formal, Appreciative, Concise).
- **Adjustable Length**: Generate short, medium, or detailed replies.
- **Languages**: Multi-language selection feature included.
- **Theme Toggle**: Light and Dark mode options.
- **Download/Copy**: Easily copy to clipboard or download as a .txt file.
- **Privacy-first**: No database required, completely frontend in the current demo structure.

## Structure
- `index.html`: The main Application layout
- `style.css`: Pure CSS for modern SaaS aesthetics
- `script.js`: Core application logic (vanilla JS)
- `.env`: Ready for the Groq API Key

## Usage
Simply open `index.html` in a browser or use a live server to run it.

For development:
```bash
npx serve
```
